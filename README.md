## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Mod Library** | Organize installed Stalker 2 mods with category and status |
| **Load Order** | Set and manage mod load priority with conflict detection |
| **Conflict Checker** | Detect file conflicts between installed Stalker 2 mods |
| **Profile System** | Save named mod configurations for different playthrough styles |
